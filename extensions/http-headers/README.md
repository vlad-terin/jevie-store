# HTTP Headers

A site's response at a glance as a card while you type: status, server, caching, and which security headers it sends.

## Type

- “headers github.com”
- “http headers https://example.org/path”

The grade counts six security headers (HSTS, CSP, X-Content-Type-Options, X-Frame-Options or CSP frame-ancestors, Referrer-Policy, Permissions-Policy): A+ for all six. ↵ copies every header.

## Reaches

The site itself (a HEAD request, or GET when HEAD is refused). It changes nothing.
