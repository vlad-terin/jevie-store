# DOI Citation

A paper's citation from its DOI, as a card while you type - APA, MLA, Chicago, Harvard, IEEE, Vancouver or BibTeX - formatted by doi.org.

## Type

- “cite 10.1038/nature12373”
- “cite 10.1038/nature12373 mla”
- “doi 10.1145/3292500.3330701 bibtex”

doi.org asks the DOI's registry (Crossref, DataCite, mEDRA) to format the citation: APA unless you name MLA, Chicago, Harvard, IEEE, Vancouver, BibTeX or RIS. Plain text loses italics, so check against your style guide. Each is kept a month. ↵ copies it.

## Reaches

doi.org and the DOI registries behind it. It changes nothing.
