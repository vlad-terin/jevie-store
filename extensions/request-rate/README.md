# Request Rate

Traffic in requests a second as a card while you type - from a day's or a month's count - with the peak to plan capacity for.

## Type

- “rps 1m a day”
- “qps 50m a month”
- “requests per second 2.5b a month peak 5x”
- “1m requests a day per second”

A count over a second, minute, hour, day, week, month (30 days) or year, as requests a second, a minute and a day, with a peak at 3× the average unless you name another (“peak 5x”). ↵ copies the average.

## Reaches

Nothing: it is worked out on your Mac. It changes nothing.
