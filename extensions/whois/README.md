# Whois

Who registered a domain, when, and when it runs out - as a card while you type, from RDAP (whois's successor).

## Type

- “whois github.com”
- “rdap example.org”
- “is jevie.ai available”
- “domain jevie”: .com, .ai, .app, .io, .dev and .co at once

↵ copies the line: `github.com · MarkMonitor Inc. · expires 2026-10-09 (in 362 days)`. The days left turn into a warning under 30. Each domain is kept a day.

Availability comes from the registry itself: a name nobody holds is a 404 there. An ending with no RDAP service is said to be unknown, never free.

## Reaches

rdap.org, which sends the lookup to the registry of the domain (Verisign for .com, and so on). It changes nothing.
