# Event Planning

Party and event sums as cards while you type: tables for the guests, the budget per head, and how many drinks to buy.

## Type

- “tables for 120 guests 8 per table”
- “event 120 guests 9500 budget”
- “drinks for 80 guests 4 hours”

Tables seat 8 unless named. Budget per head is the total over the guests. Drinks follow the planners' rule of two a guest in the first hour, then one an hour, split half wine (5 glasses a bottle), a third beer and a sixth spirits (16 drinks a 750 mL bottle). Adjust to the crowd. ↵ copies the line.

## Reaches

Nothing: it is worked out on your Mac. It changes nothing.
