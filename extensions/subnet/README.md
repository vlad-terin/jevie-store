# Subnet Calculator

An IPv4 subnet as a card while you type: its network, broadcast, usable range, host count and mask - from CIDR or a mask.

## Type

- “cidr 10.0.0.0/24”
- “subnet 192.168.1.130/26”
- “subnet 172.16.0.0 255.255.240.0”

It shows the network, broadcast, usable range, host count, mask and wildcard, and whether the range is private. A /31 and a /32 count every address, as point-to-point links use them. ↵ copies the line.

## Reaches

Nothing: it is worked out on your Mac. It changes nothing.
