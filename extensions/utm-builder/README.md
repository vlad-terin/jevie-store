# UTM Builder

A link with UTM tags, built as a card while you type - source, medium and campaign - and copied with ↵.

## Type

- “utm https://jevie.app twitter social launch”
- “utm jevie.app source=newsletter campaign=october”

Words after the address are source, medium and campaign, in that order. Or name them: `source=` `medium=` `campaign=` `term=` `content=`. ↵ copies the link.

## Reaches

Nothing: it is built on your Mac. It changes nothing.
