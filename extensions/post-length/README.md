# Post Length

Whether a post fits each platform, as a card while you type: X, LinkedIn, Instagram, Threads, Bluesky, a meta description, an SMS - and how much shows before “see more”.

## Type

- “post length Launching our new AI launcher today”
- “char limit <a draft>”
- “post length clipboard”

Platforms: X (280; a link counts 23, an emoji 2), Threads 500, Bluesky 300, LinkedIn 3,000 (about 210 shown before “see more”), Instagram 2,200 (125 shown), Facebook, a meta description 160, a title tag 60, a Google Ads headline 30, an SMS 160. ↵ copies the counts.

## Reaches

Nothing: it is counted on your Mac (the clipboard only when you say “clipboard”). It changes nothing.
