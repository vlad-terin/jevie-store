# SEO Check

A page's search basics as a card while you type: its title and description lengths, H1, canonical, indexing, language and a Google-style preview.

## Type

- “seo github.com”
- “seo vercel.com/pricing”

It reads the title (Google shows about 60 characters), the meta description (about 160), the H1s, the canonical link, the robots rules and the page language, and draws the page as a search result would look. The six checks give a score out of 6. ↵ copies the title, the description and what to fix.

## Reaches

The page itself. It changes nothing.
