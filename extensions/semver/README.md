# Semver

Whether a version satisfies a range, and what a range like ^1.2.0 or ~2.1 allows, as a card while you type - npm's rules, on your Mac.

## Type

- “semver ^1.2.0”
- “semver ~2.1 2.1.9”
- “semver >=1.2 <2 1.9.0”
- “semver 1.x 1.5.2”

It reads npm's ranges: caret, tilde, x-ranges and comparators. A pre-release only satisfies a range that names one. A version after the range is tested against it. ↵ copies the answer.

## Reaches

Nothing: it is worked out on your Mac. It changes nothing.
