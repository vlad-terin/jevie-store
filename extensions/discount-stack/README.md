# Stacked Discounts

What stacked discounts really take off, as a card while you type: 20% off then 10% off is 28%, not 30% - with the final price.

## Type

- “20% off then 10% off 80”
- “80 with 25% off and 15% off”
- “150 with 30% off then 20% off plus 8% tax”

Each discount is taken off what the one before left: 20% then 10% is 28% off, not 30%. Tax, if named, is added after. ↵ copies the final price.

## Reaches

Nothing: it is worked out on your Mac. It changes nothing.
