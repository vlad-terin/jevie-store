# Media Math

Creator sums as cards while you type: a video's file size from its bitrate, how long a script takes to read aloud, and how big a photo prints.

## Type

- “video size 10 min at 8 mbps”
- “video 45 min 4k”
- “speaking time 1500 words”
- “script 900 words at 160 wpm”
- “print size 6000x4000 at 300 dpi”

Video size is bitrate × time; a resolution alone uses YouTube's recommended SDR upload bitrates (720p 5, 1080p 8, 1440p 16, 4K 45 Mbps at 30 fps), audio not counted. Speaking time is 150 words a minute unless named. Print size is pixels ÷ dpi, 300 unless named, with the size at 150 dpi for a wall print. ↵ copies the line.

## Reaches

Nothing: it is worked out on your Mac. It changes nothing.
