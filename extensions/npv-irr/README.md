# NPV & IRR

Net present value and internal rate of return of cash flows, as cards while you type - plus payback period - for an investment, a project or a deal.

## Type

- “npv 8% -10000 3000 4000 5000”
- “irr -10000 3000 4000 5000”

The first cash flow is today, usually the outlay as a negative; each one after it is a period later. The NPV card gives the IRR and payback period too. ↵ copies the line.

## Reaches

Nothing: it is worked out on your Mac. It changes nothing.
