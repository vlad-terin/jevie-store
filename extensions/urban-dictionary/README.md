# Urban

What slang means, from Urban Dictionary, as a card while you type: the top definition and an example.

## Type

- “urban yeet”
- “urban touch grass”
- “slang for no cap”

↵ copies the definition. A shop's name after “urban” finds a definition too (“urban outfitters”): arrow down to the list to open the site instead. Urban Dictionary is written by its readers, and some of it is crude. The top definition is the one with the most thumbs up over thumbs down. A proper dictionary definition is Jevie's own: “define serendipity”.
