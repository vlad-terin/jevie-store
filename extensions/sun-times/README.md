# Sunrise & Sunset

When the sun rises and sets anywhere today, and how long the day is, as a card while you type - from Open-Meteo.

## Type

- “sunrise tokyo”
- “sunset in lisbon”
- “daylight reykjavik”

↵ copies the line: `Tokyo: sunrise 5:43 AM, sunset 5:12 PM (11 h 29 min)`. The times are local to the place.

## Reaches

geocoding-api.open-meteo.com and api.open-meteo.com. It changes nothing.
