# CSS Clamp

A fluid CSS size as a card while you type: the clamp() that grows from a minimum at one screen width to a maximum at another - and px to vw.

## Type

- “clamp 16px 24px 320 1280”
- “fluid 1rem 1.5rem 360px 1440px”
- “24px to vw at 1440”
- “5vw at 390”

The clamp() grows linearly from the minimum size at the first width to the maximum at the second, written in rem (16px root unless “base 18”) so it still follows the reader's zoom. ↵ copies the CSS.

## Reaches

Nothing: it is worked out on your Mac. It changes nothing.
