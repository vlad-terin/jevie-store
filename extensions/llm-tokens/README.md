# LLM Tokens

How many tokens a text or a word count is, roughly, and whether it fits common context windows - as a card while you type.

## Type

- “tokens 2000 words”
- “tokens 15k words”
- “tokens clipboard”

It estimates tokens as about 4 characters or 0.75 English words each, the rule of thumb of the common tokenizers, and shows which common context windows (8k, 32k, 128k, 200k, 1M) the text fits. Each model counts a little differently, more so for code and other languages. ↵ copies the count.

## Reaches

Nothing: it is counted on your Mac (the clipboard only when you say “clipboard”). It changes nothing.
