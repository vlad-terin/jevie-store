# Portfolio Math

A portfolio's numbers as cards while you type: the Sharpe ratio, a weighted expected return, and real (after-inflation) return.

## Type

- “sharpe 12% return 15% vol 4%”
- “expected return 60% at 8% 40% at 3%”
- “real return 7% inflation 3%”

Sharpe is the return over the risk-free rate (4% unless named), divided by volatility. Expected return weights each holding's return (weights not adding to 100% are scaled). Real return uses the Fisher equation. ↵ copies the line.

## Reaches

Nothing: it is worked out on your Mac. It changes nothing.
