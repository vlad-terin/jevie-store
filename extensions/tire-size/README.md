# Tire Size

What a tire size code means, as a card while you type - its diameter, sidewall and revolutions per mile - and how two sizes compare on the speedometer.

## Type

- “tire 225/45r17”
- “225/45r17 vs 245/40r18”

It reads the size code (width in mm / sidewall as a % of width R rim in inches) and gives the overall diameter, the sidewall, and revolutions a mile. Two sizes give the difference and the true speed at an indicated 60; within ±3% is the usual rule for a swap. ↵ copies the result.

## Reaches

Nothing: it is worked out on your Mac. It changes nothing.
