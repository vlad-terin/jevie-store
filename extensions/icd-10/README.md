# ICD-10

ICD-10-CM codes as a card while you type: a condition's codes, or what a code means - from the National Library of Medicine.

## Type

- “icd10 asthma”
- “icd-10 type 2 diabetes”
- “icd J45.909”

A code (J45.909) finds its name; words find up to six codes, the best first. ↵ copies the first code.

## Reaches

clinicaltables.nlm.nih.gov (the National Library of Medicine). It changes nothing.
