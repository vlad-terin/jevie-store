# Service Status

Is GitHub, OpenAI, Slack or Vercel down? A service's own status page as a card while you type, with what is broken right now.

## Type

- “is github down”
- “status openai”
- “vercel status”
- “is slack up”

It knows the status pages of about 40 services (GitHub, OpenAI, Anthropic, Vercel, Cloudflare, Slack's Atlassian-hosted peers, Jira, Linear, Figma, Notion, Supabase and more). Another service is tried at `status.<name>.com`. It shows what is broken and the open incidents. ↵ copies the line with the status page's address.

## Reaches

The service's own status page. It changes nothing.
