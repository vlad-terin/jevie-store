# Weighted Average

A weighted average as a card while you type - values with weights as percentages or counts - for grades, portfolios or survey scores.

## Type

- “weighted average 90 30% 80 70%”
- “weighted average 88 at 20% 92 at 30% 75 at 50%”
- “weighted average 4.5 x 120 3.9 x 40”

Each value is multiplied by its weight and the total divided by the weights' sum; weights can be percentages (they need not add to 100, and it says when they do not) or counts. The plain average is shown beside it. ↵ copies the average.

## Reaches

Nothing: it is worked out on your Mac. It changes nothing.
