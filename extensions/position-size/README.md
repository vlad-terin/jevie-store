# Position Size

How many shares to buy so a stop-loss risks only what you chose, as a card while you type - with the position's size and the reward-to-risk.

## Type

- “position size account 10000 risk 1% entry 50 stop 48”
- “position size 25k risk 2% entry 120 stop 114 target 135”

Shares = account × risk ÷ the distance from entry to stop, never more than the account can buy. A stop above the entry is a short. A target adds the reward-to-risk. ↵ copies the share count.

## Reaches

Nothing: it is worked out on your Mac. It changes nothing.
