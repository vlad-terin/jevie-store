# ISBN Lookup

A book from its ISBN as a card while you type: title, authors, publisher, year and pages - from Open Library - and its citation.

## Type

- “isbn 9780262033848”
- “isbn 0-262-03384-4”

The check digit is checked first, for ISBN-10 and ISBN-13, so a mistyped number is said to be one. Open Library supplies the title, authors, publisher, year and pages. ↵ copies a simple citation (author, year, title, publisher).

## Reaches

openlibrary.org. It changes nothing.
