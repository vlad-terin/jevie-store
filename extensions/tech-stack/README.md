# Tech Stack

What a site is built with, as a card while you type - its framework, CMS, hosting, CDN, analytics and marketing tools - like BuiltWith, from the open webappanalyzer fingerprints.

## Type

- “built with vercel.com”
- “tech stack github.com”
- “what is stripe.com built with”

It finds what can be seen without running the page: headers, cookies, HTML, script addresses, meta tags and the address itself, plus what those imply (Next.js implies React). Things a page only sets up in JavaScript as it runs are not seen, which BuiltWith's crawler would catch. The fingerprints (webappanalyzer, GPL-3.0) are fetched once a week. ↵ copies every technology found, by group.

## Reaches

raw.githubusercontent.com (the fingerprints, weekly) and the site itself. It changes nothing.
