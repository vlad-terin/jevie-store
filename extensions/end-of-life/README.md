# End of Life

When a language, framework, database or OS stops getting fixes, as a card while you type - the current and supported releases, from endoflife.date.

## Type

- “eol python”
- “eol node 18”
- “end of life ubuntu”
- “eol postgresql 13”

Without a release, it shows the newest and every supported one. With one, it shows whether that release is supported and until when. Common names work: node, postgres, k8s, rails, golang. ↵ copies the line.

## Reaches

endoflife.date. It changes nothing.
