# Tempo

A tempo as delay and reverb times, as a card while you type: the milliseconds of each note value, dotted and triplet - for producers and musicians.

## Type

- “bpm 120”
- “tempo 92 bpm”
- “120 bpm”

A beat (a quarter note) is 60000 ÷ BPM milliseconds. Each note value is shown straight, dotted (× 1.5) and triplet (× 2/3), for setting delays, reverb pre-delay and LFO rates by ear. ↵ copies the table.

## Reaches

Nothing: it is worked out on your Mac. It changes nothing.
