# npm Downloads

How much an npm package is used, as a card while you type: its weekly and monthly downloads, and how that compares with the month before.

## Type

- “npm downloads react”
- “npm downloads zod vs yup vs valibot”

It reads npm's downloads API: the last week, the last 30 days, and the change on the 30 days before. Name several with “vs” to compare them. Counts include CI installs and mirrors, so they measure use loosely. ↵ copies the line.

## Reaches

api.npmjs.org. It changes nothing.
