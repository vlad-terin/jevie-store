# Obsidian

Search your Obsidian vault and read notes beside the list; return opens the note in Obsidian. Read-only - a lean port of Raycast's Obsidian extension.

## Say

- “obsidian notes”
- “obsidian note networking”

## Settings

- **Vault folder**: Empty: the vault Obsidian itself lists first.

“settings for obsidian” changes them; secrets are kept in the Keychain.
