# Calories & Macros

Daily calories by Mifflin-St Jeor with your activity, and grams of protein, carbs and fat for a macro split - as cards while you type.

## Type

- “tdee 30 male 180cm 80kg moderate”
- “calories 28 f 5'6 140 lb active cut”
- “macros 2400 calories 40/30/30”

Daily calories use Mifflin-St Jeor for the resting rate (BMR), times an activity level (sedentary 1.2, light 1.375, moderate 1.55, active 1.725, very active 1.9). “Cut” takes off 500, “bulk” adds 300. Macros turn a split into grams. Estimates, not advice. ↵ copies the line.

## Reaches

Nothing: it is worked out on your Mac. It changes nothing.
