# Design Math

The sums designers do all day, as cards while you type: an aspect ratio, a size scaled to a new width or height, and px to rem.

## Type

- “aspect ratio 1920x1080”
- “ratio 1080 by 1350”
- “1920x1080 to width 1280”
- “24px to rem”
- “1.5rem to px”

The aspect ratio is named when it is a common one (16:9, 4:5, 1.91:1 for link cards…). A resize keeps the proportion. px ↔ rem uses a 16px root unless “base 18”. ↵ copies the answer.

## Reaches

Nothing: it is worked out on your Mac. It changes nothing.
