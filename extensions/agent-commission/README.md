# Agent Commission

A real-estate commission split as a card while you type: the total, each side's share, and what the agent keeps after the broker split.

## Type

- “commission split 500000 at 6%”
- “commission split 750k at 5% 50/50 80/20”
- “realtor fee 420k at 5.5%”

The total is price × rate. It splits between the listing and buying sides (50/50 unless named), then one side between agent and broker (70/30 unless named). Before fees, franchise cuts and tax; rates are negotiable and vary by market. ↵ copies the line.

## Reaches

Nothing: it is worked out on your Mac. It changes nothing.
