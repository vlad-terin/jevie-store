# Country

A country at a glance as a card while you type: its flag, capital, region, languages, currencies, calling code and time zones.

## Type

- “country japan”
- “country de”
- “country of the capital ottawa”

↵ copies the line: `Japan 🇯🇵 · Tokyo · Japanese · JPY · +81`. A name, an official name, a two- or three-letter code, another language's name or a capital all find it.

## Reaches

raw.githubusercontent.com (the mledoze/countries dataset, read once a month). It changes nothing.
