# Bundle Size

A card under the field as you type: what an npm package costs a web page,
minified and gzipped, with its dependency count and whether it is an ES
module. From [bundlephobia](https://bundlephobia.com), no key. Each package
is kept a day.

## Type

- “bundle size zod”
- “bundle size react-dom@18.3.1”: one version
- “package size date-fns”

↵ copies the line: `zod@4.6.6: 88.9 kB min+gzip`.

## Reaches

bundlephobia.com. It changes nothing.
