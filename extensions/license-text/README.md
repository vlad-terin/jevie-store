# License Text

An open-source licence's text as a card while you type - MIT, Apache 2.0, GPL, BSD and more from the SPDX list - with the year and your name filled in.

## Type

- “license mit”
- “license apache-2.0”
- “license gpl-3.0”
- “license bsd 3”

It reads the licence's text from the SPDX licence list and fills in the year and the copyright holder (your name from git config on this Mac; nothing is sent). It shows in a line what kind of licence it is. Not legal advice about which to choose. ↵ copies the text.

## Reaches

raw.githubusercontent.com (the SPDX licence texts). Your git user.name is read locally and is not sent. It changes nothing.
