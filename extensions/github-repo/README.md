# GitHub Repo

A GitHub repository at a glance as a card while you type: stars, forks, its latest release, last push and licence.

## Type

- “repo vercel/next.js”
- “gh repo sqlite/sqlite”

↵ copies the repository's address. “github repo <words>” stays the GitHub extension's search; this card is one repository, by owner/name. A github.com address you type stays one to open.

## Reaches

api.github.com (60 requests an hour without a token; GITHUB_TOKEN or GH_TOKEN raises it, and past it the `gh` CLI you are signed into answers). It changes nothing.
