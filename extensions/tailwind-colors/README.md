# Tailwind Colors

A Tailwind CSS color as a card while you type: its hex, RGB and HSL, the shades beside it, and the class names - from Tailwind's own palette.

## Type

- “tailwind blue-500”
- “tw emerald 300”
- “tailwind slate”

It reads Tailwind's own default palette (v3.4) from its repository once a month. The shade is 500 unless named. It shows the hex, RGB and HSL, the shades either side as swatches, and the class names. ↵ copies the hex.

## Reaches

raw.githubusercontent.com (Tailwind's palette, monthly). It changes nothing.
