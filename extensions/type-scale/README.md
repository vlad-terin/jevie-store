# Type Scale

A modular type scale from a base size and a ratio, as a card while you type - major third, perfect fourth, golden - and the golden-ratio split of a width.

## Type

- “type scale 16 1.25”
- “type scale 18 perfect fourth”
- “golden ratio 960”

A modular scale multiplies a base size by a ratio for each step, two down and six up. Name a ratio (minor second 1.067, major second 1.125, minor third 1.2, major third 1.25, perfect fourth 1.333, augmented fourth 1.414, perfect fifth 1.5, golden 1.618) or give a number. The golden-ratio card splits a length into φ parts. ↵ copies the result.

## Reaches

Nothing: it is worked out on your Mac. It changes nothing.
