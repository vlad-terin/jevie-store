# DNS Lookup

A card under the field as you type: a domain's DNS records. It shows A, AAAA,
CNAME, MX and NS, plus how many TXT records it has (and whether one is SPF).
They come from your Mac's own resolver, so nothing is sent anywhere but the
lookups themselves.

## Type

- “dns github.com”
- “nslookup mail.google.com”

↵ copies every record, one per line.

The card needs a domain after the word, so “flush dns” and “dns cache” stay
Jevie's own. “dig” is Jevie's file finder, so it is not this card's.

## Reaches

The DNS servers your Mac uses. It changes nothing.
