# IP Info

Where an IP address is and whose network it belongs to, as a card while you type - from ipwho.is.

## Type

- “ip 8.8.8.8”
- “ip 2606:4700:4700::1111”
- “whois ip 1.1.1.1”

↵ copies the line: `8.8.8.8 · Google LLC (AS15169) · Mountain View, US`. A private address (10.x, 192.168.x, …) is said to be one, and nothing is sent. Your own public address is Jevie's: “what is my ip”.

## Reaches

ipwho.is (the address typed). It changes nothing.
