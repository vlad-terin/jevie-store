# Grade Calculator

What score a final exam needs for the grade you want, and a GPA from letter or number grades - as cards while you type.

## Type

- “grade needed current 78 target 82 final 30%”
- “gpa A B+ A- B”
- “gpa A 4 B+ 3 C 2”

The final-exam card works out the score that lifts the current grade to the target, given the final's weight, and says when even 100% is not enough. The GPA uses the common US 4.0 scale (A 4.0, A− 3.7, B+ 3.3 …); a number after a letter grade is its credits. ↵ copies the result.

## Reaches

Nothing: it is worked out on your Mac. It changes nothing.
