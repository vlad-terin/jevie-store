# MIME Types

A file extension's MIME type, or the extensions of a MIME type, as a card while you type - for headers, uploads and servers.

## Type

- “mime webp”
- “mime type .docx”
- “content type for woff2”
- “mime application/json”

About 110 common types: web, images, audio, video, fonts, documents, archives, apps and 3D, from IANA's registry and what browsers send. An extension gives its type (and the Content-Type header, with a charset for text); a type gives its extensions. ↵ copies the answer.

## Reaches

Nothing: the table is in the extension. It changes nothing.
