# Travel Distance

How far apart two places are and roughly how long the flight takes, as a card while you type - the great-circle distance in kilometres and miles.

## Type

- “distance london to tokyo”
- “how far is paris from berlin”
- “flight time new york to paris”

The distance is the great-circle one (haversine), as the crow flies. The flight time assumes about 850 km/h plus half an hour for taxi, climb and descent, a rough guide: winds and routes make real flights longer or shorter. ↵ copies the line.

## Reaches

geocoding-api.open-meteo.com (each place once). It changes nothing.
