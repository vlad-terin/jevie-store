# F1 Standings

The Formula 1 championship as a card while you type: the leader, the top five and the gaps - drivers or constructors, from Jolpica's F1 data.

## Type

- “f1 standings”
- “f1 constructors”
- “formula 1 drivers”

↵ copies the leader and the top five, one per line.

## Reaches

api.jolpi.ca. It changes nothing.
