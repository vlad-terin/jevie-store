# A/B Test

Whether an A/B test's difference is real, as a card while you type - the lift, the confidence and the p-value - and how many visitors a test needs.

## Type

- “ab 120/2400 vs 150/2380”
- “sample size 4% baseline 10% lift”
- “sample size 4% baseline 1% lift absolute”

The test is a two-sided z-test on the two conversion rates; 95% confidence (p < 0.05) is called significant. The sample size is per variant, for 95% confidence and 80% power; a lift is relative unless “absolute” follows it. ↵ copies the verdict.

## Reaches

Nothing: it is worked out on your Mac. It changes nothing.
