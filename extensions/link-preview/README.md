# Link Preview

How a link will look when shared: its Open Graph title, description, image and card type, as a card while you type - and the tags it is missing.

## Type

- “og github.com”
- “preview https://vercel.com”
- “open graph stripe.com/pricing”

It shows the title, description and image a share would use, and says which tags are missing (og:title, og:image, description, twitter:card). Only the page's head is read, at most 512 kB. ↵ copies the title, description and image address.

## Reaches

The page itself. It changes nothing.
