# Exit Codes

What a process exit code or a Unix signal means, as a card while you type - 137 is SIGKILL, often the out-of-memory killer.

## Type

- “exit code 137”
- “exit status 127”
- “signal 15”
- “sigsegv”

Exit codes 0, 1, 2, 126, 127, 128 and 255 are the shell's; 129 to 159 are 128 + a signal (137 = SIGKILL, 139 = SIGSEGV, 143 = SIGTERM); others belong to the program. Signals are named for the numbers Linux and macOS share. ↵ copies the meaning.
