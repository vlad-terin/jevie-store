# Curl to Fetch

A curl command turned into JavaScript fetch() as a card while you type - method, headers, body and auth - ready to paste.

## Type

- “curl to fetch curl -X POST https://api.example.com/items -H "Content-Type: application/json" -d '{"name":"a"}'”
- “curl to fetch curl https://api.github.com/user -u octo:token”

It reads curl's -X, -H, -d (and --data-raw, --json), -u, -A, -b and -e, and notes what has no fetch equivalent (-k). Nothing is requested. Start with “curl to fetch” so that a curl typed to be run stays the shell's. ↵ copies the code.

## Reaches

Nothing: it is converted on your Mac. It changes nothing.
