# Linear

Your Linear issues - assigned, or searched by words - read-only, with a personal API key kept in the Keychain. A lean port of Raycast's Linear extension.

## Say

- “linear issues”
- “linear issue onboarding”

## Settings

- **Linear API key** (required): linear.app → Settings → Security & access → Personal API keys.

“settings for linear” changes them; secrets are kept in the Keychain.
