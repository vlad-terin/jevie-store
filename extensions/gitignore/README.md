# Gitignore

A .gitignore for a language or tool as a card while you type - GitHub's own templates - and ↵ copies the file.

## Type

- “gitignore node”
- “gitignore python”
- “gitignore swift xcode macos”

It uses GitHub's own templates (github/gitignore), joined when you name several (a language, an editor, an OS). Common names work: node, ts, py, golang, vscode, mac. Each template is kept a week. ↵ copies the whole file.

## Reaches

raw.githubusercontent.com (the github/gitignore templates). It changes nothing.
