# SSL Certificate

A site's TLS certificate as a card while you type: who issued it, when it runs out, and the names it covers - read from the server itself.

## Type

- “ssl github.com”
- “cert example.org:8443”
- “tls api.stripe.com”

↵ copies the line: `github.com · Sectigo · expires 2026-02-05 (in 116 days)`. It says whether this Mac trusts the certificate, and why not when it does not.

## Reaches

The site itself, on its TLS port (443 unless one is typed). It changes nothing.
